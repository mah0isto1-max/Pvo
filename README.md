# Крупнокалиберное ПВО на ComputerCraft + Create Big Cannons + Create Radar

Автоматизированный зенитный комплекс (ПВО) для Minecraft 1.21.1 с модами:
- **CC: Tweaked**
- **Create: Big Cannons (CBC)**
- **Create Radar**

## 1. Концепция и боеприпасы
- **Калибр**: Тяжелые стальные/чугунные стволы (Cast Iron / Steel Cannon).
- **Снаряд**: Крупнокалиберный фугасный снаряд (**HE Shell**).
- **Взрыватель**: Бесконтактный взрыватель (**Proximity Fuze**). 
  - Дистанция срабатывания настраивается ПКМ (обычно 4–7 блоков).
  - Снаряду не обязательно прямое попадание в корпус: при пролете рядом с самолетом/дирижаблем бесконтактный взрыватель детонирует фугасный заряд, нанося колоссальный урон взрывной волной и осколками.

---

## 2. Схема сборки орудия и блоков

```
           [Ствол орудия CBC]
                   │
           [Cannon Mount]
                   │
   ┌───────────────┼───────────────┐
   │               │               │
[Pitch Controller] [Yaw Controller][Fire Controller]
   │               │               │
   └───────────────┴───────────────┘
                   │ (Проводные модемы CC:Tweaked)
             [Компьютер CC]
                   │
         [Радар (Plane Radar)]
```

### Необходимые блоки:
1. **Radar Bearing** (с тарелками) или **Plane Radar** из мода *Create Radar*.
2. **Auto Pitch Controller** — крепится к валу наклона ствола (Pitch).
3. **Auto Yaw Controller** — крепится к поворотному механизму лафета (Yaw).
4. **Auto Fire Controller** — подключен к казенной части/механизму спуска.
5. **Advanced Computer** (Компьютер из CC: Tweaked).
6. **Wired Modem** (Проводные модемы) + сетевой кабель для объединения контроллеров и радара в одну сеть.

## 3. Математика упреждения и баллистики
Скрипт выполняет расчет точки встречи с целью методом последовательных итераций:
1. Радар возвращает вектор текущих координат `(x, y, z)` и вектор скорости цели `(vx, vy, vz)`.
2. Компьютер находит расстояние до цели и ориентировочное время подлета:  
   $$t = \frac{\text{Distance}}{V_{\text{снаряда}}}$$
3. С учетом скорости цели находится прогнозная точка:  
   $$\vec{P}_{\text{предсказанная}} = \vec{P}_0 + \vec{V}_{\text{цели}} \cdot t$$
4. Рассчитывается гравитационное падение снаряда:  
   $$\Delta y = \frac{1}{2} g t^2$$
5. Орудие доводится сервоприводами, и при попадании углов в коридор допустимой погрешности (`aimTolerance`) производится импульс на спуск (`fireOn`).

## 4. Калибровка в `pvo_aa_control.lua`
В начале файла задайте параметры вашей пушки:
```lua
muzzleVelocity = 60.0  -- Начальная скорость снаряда (зависит от числа пороховых зарядов и длины ствола)
gravity = 1.0          -- Поправка на падение снаряда
minRange = 25.0        -- Мертвая зона (ближе не стрелять)
maxRange = 450.0       -- Предельная дальность обнаружения радара
aimTolerance = 1.5     -- Точность сведения (градусы) перед выстрелом
```

---

## 5. Запуск в игре
1. Разместите дискету или скопируйте файл в папку сохранений мира:  
   `saves/<мир>/computercraft/computer/<ID_компьютера>/pvo.lua`
2. Наберите в терминале компьютера:
   ```sh
   pvo
   ```
